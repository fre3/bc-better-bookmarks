# Indexfold v1.0.0

**Your bookmarks, beautifully within reach.**

A typography-first bookmark dashboard with instant search and keyboard navigation. Built for Chrome and Edge.

## What's included

- A typographic New Tab catalogue with root navigation, inline folders, sheet previews and light/dark/System appearance.
- Local search across titles, URLs, folder paths and effective tags; `#tag` and `@folder` filters; Escape restores browsing context.
- A configurable dashboard-search command (suggested Ctrl+Shift+B on Windows), and dashboard-local Alt+1–9 root shortcuts.
- Bookmark/folder editing, creation, native drag/move, keyboard Move and confirmed deletion.
- Direct and inherited folder tags, archive controls, device-local Show archived and explicit folder-binding review.
- Protected Edge Workspace containers with ordinary bookmark/subfolder operations, including moves between containers.
- A [practical user guide](https://github.com/fre3/indexfold/blob/v1.0.0/docs/user-guide.md), also linked from Manage, and real synthetic-data screenshots.

This release includes the 0.1.28 ResizeObserver feedback correction and 0.1.29 removal of redundant search-path suffixes. Release packaging also corrects a Windows-only shortcut declaration that prevented Linux Chromium from loading the extension. No metadata reset or identity migration is performed.

## Install or update

Download **indexfold-1.0.0-unpacked.zip** and its `.sha256` checksum. Extract the ZIP into a permanent folder; `manifest.json` is at its root. In `chrome://extensions` or `edge://extensions`, enable Developer mode and choose **Load unpacked**. Select that folder, then open a new tab. Configure the actual shortcut at your browser's `extensions/shortcuts` page.

For an existing unpacked installation, replace files in its existing folder, reload the extension and open a fresh tab. Do not uninstall merely to update; the public key and extension ID are unchanged. This is a **GitHub unpacked-extension release**, not a Chrome Web Store or Edge Add-ons listing.

## Permissions and limits

Permissions: `bookmarks` for native reading/mutations; `storage` for metadata/preferences; `favicon` for browser-provided icons; `tabs` for finding/reusing the dashboard. No host permissions or content scripts. Search has no backend; browser synchronization and browser favicon loading may involve network activity. Opening bookmark/help/footer links navigates to their destinations.

- Browser bookmarks and extension metadata use separate stores; failures can be partial. Follow the recovery message rather than blindly repeating a mutation.
- Folder identity may require explicit confirmation on another device. Ambiguous bindings remain unresolved. Sync depends on browser accounts, delivery and quotas; there is no Chrome-to-Edge sync service.
- Edge's address bar may retain focus when invoking search on an already-open dashboard; Ctrl+F6 is the accepted fallback.
- Edge Workspace containers remain protected. Workspace-to-ordinary-root moves are restricted; active-Workspace filtering is not implemented.
- Deletion affects native bookmarks and browser sync; there is no Undo. Diagnostics may contain private bookmark data.

Automated unit, rendered Chromium and extracted-extension checks passed. Prior native Edge and two-PC successes are recorded separately; v1.0.0 has not received a fresh native Windows Edge or macOS review.
