## Screenshot provenance

The three `docs/images/*.png` files are actual 1.0.0 UI captures at 1280×900, device scale 1, in bundled Chromium 153.0.8010.12 on Linux. `scripts/check-release.mjs dist --capture` creates a new temporary profile, seeds only invented/example bookmarks through the native browser API and sets tags/archive through the real UI. It never accepts an existing user-profile path. All images were opened and visually inspected; no private data or visible native IDs/diagnostics appear. PNGs are approximately 60–112 KiB each, preserving readable text without a large asset payload.

The extension is loaded using the browser-level [CDP Extensions.loadUnpacked method](https://chromedevtools.github.io/devtools-protocol/tot/Extensions/#method-loadUnpacked); the available bundled browser's command-line loading attempt did not yield a worker. No test/debugging flags enter the shipped manifest or runtime code.

## Verification and publication

`npm ci` and `npm run check` pass: 261 tests / 25 files, typecheck, lint, production build and stable extension-ID check. Focused browser checks cover ResizeObserver window errors/settled geometry, actual pointer duplicate moves, Workspace outcome verification, management/modal drafts, search restoration, appearance, sticky navigation and footer wheel/peek lifecycle. See the current handoff for the publication result.

`scripts/package-release.py` deterministically ZIPs only runtime `dist/` files, with manifest at the archive root and a SHA-256 sidecar. Extraction is byte-compared to dist and the same production browser check runs against the extracted files. The tag workflow rebuilds/checks dist, verifies the tag is on master history, packages and publishes the regular GitHub release. It uses the job's scoped GitHub token, not a committed credential.

Native evidence is separate: accepted 0.1.27, user-verified cross-Workspace/two-PC sync, and the specific later 0.1.28/0.1.29 reports already recorded in the handoff. No new Windows Edge, macOS, store-installed or cross-browser synchronization claim is made by these Linux Chromium checks. The historical title-change cause remains unconfirmed and its investigation closed.
